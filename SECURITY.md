# Security Policy

Convene stores personal data about beneficiaries of NGO programs. Please treat
any issue that could expose or change this data with care.

## Reporting a vulnerability

Do not report security issues in public issues, discussions or pull requests.

Report them privately:

1. Use GitHub
   [private vulnerability reporting](https://github.com/mahiti-org/convene/security/advisories/new), or
2. Email convene@mahiti.org.

Include a description of the issue, steps to reproduce and the affected part of
Convene. We will acknowledge your report and keep you informed until it is
fixed.

## Beneficiary data

- Never include real beneficiary or personal data in a report. Use test data.
- Only test against your own local or test installation.
- If you come across real personal data on a live deployment, stop accessing it,
  do not share it, and tell us which deployment is affected.
